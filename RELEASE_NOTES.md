PathRenamer 1.4.1 makes the preview table easier to read.

- Every column in the preview (Original Filename, Detected Match, New Path, Subtitles, Status) can be made wider or narrower by dragging its edge, in both the Modern and Classic layouts.
- Long names wrap onto more lines instead of being cut off with "…".

Everything from 1.4.0 is included: fixing single rows, copy/hard-link, rename history, movie editions, presets and the new themes.

Install with **PathRenamer-Setup-1.4.1.exe**. It upgrades an existing installation and keeps your settings. **PathRenamer.exe** is the same app without an installer.
