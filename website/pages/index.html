What it does

From release names to names your media server understands

Release names are full of tags media servers can't use. PathRenamer finds the real title, year and episode, looks up episode titles, and builds the folders for you.

Pick your downloads

Drop a folder or files on the window, and choose TV Shows, Movies or Anime.

Check the preview

Every new name is shown before anything moves. Anything unsure is marked, and one right-click fixes a row.

Rename

Features

Everything a tidy media library needs

Names every server knows

Movies, TV shows, anime, multi-episode files, daily shows, specials and movie editions, named the way Plex, Jellyfin, Emby and Kodi match them, and apps like Plezy show them.

Subtitles come along

Subtitles next to the video or in a Subs folder get the right language code: .eng.srt, .spa.forced.srt, .eng.sdh.srt.

Download missing subtitles

Get subtitles from OpenSubtitles.com in your languages. The ones made for your exact file come first.

Watch folder PRO

Point it at Downloads. New movies and episodes are renamed into your library as soon as they finish downloading.

Your server scans right away PRO

Connect Plex, Jellyfin, Emby or Kodi once. After each rename it scans just the folders that changed, so new episodes appear in seconds.

Keep seeding

Hard links put files in your library without moving the download or using extra space, so torrents keep seeding.

Undo anything

Undo the last rename, or any earlier one from the rename history, even after a restart.

Quality from the file

No tags in the name? Resolution and codecs are read from the video itself: Home Video (2019) 1080p H.264.

Make it yours

Naming formats, presets, a Modern or Classic layout, and dark, light or custom themes.

Stays out of the way

Closed, it keeps watching from the tray, and it can start with Windows. New versions install with one click.

Docker for servers and NAS

The same renaming on Linux, a Mac, Synology, Unraid or a Raspberry Pi, with every free feature. Set it up.

Free and open source

Renaming by hand is free, for good, and the code is public under the GPL. Pro pays for the automatic parts.

Automation

Downloads that file themselves

Turn on the watch folder and PathRenamer waits until each download is complete, matches it, and renames it into the right library folder. Files it isn't sure about wait in the preview for you.

Then it fetches missing subtitles and tells Plex, Jellyfin, Emby or Kodi to scan. You just press play.
