Install in four steps

  1. Open the latest release and download PathRenamer-Setup-{{ version }}.exe.
  2. Run it. If Windows shows Windows protected your PC, click More info, then Run anyway. That warning appears for apps from new publishers without a paid code-signing certificate; the installer is built by GitHub from the public source code.
  3. Start PathRenamer and choose your library folders (TV Shows, Movies, Anime) when it asks.
  4. Drop a downloads folder on the window, click Preview, then Rename Files.

Updating is one click: when a new version is out, Update to … appears at the bottom right of PathRenamer. Click it and the new version is downloaded, checked and installed, with your settings and rename history kept. Prefer no installer? PathRenamer.exe on the same page runs on its own, and updates itself the same way.

New to Plex naming? Read how to name movies and TV shows for Plex. PathRenamer does all of it for you, but it helps to know what good names look like.

On a server, NAS, Linux or Mac: Docker

The Docker version names files exactly like the Windows app and has every free feature. With Pro it renames new downloads on its own. Save this as docker-compose.yml, change the folders on the left of each :, and run docker compose up -d:

services:
  pathrenamer:
    image: ghcr.io/royalkiller2222/pathrenamer:latest
    restart: unless-stopped
    environment:
      PUID: "1000"
      PGID: "1000"
      PATHRENAMER_WATCH: /data/downloads
      PATHRENAMER_MOVIES: /data/media/movies
      PATHRENAMER_TV: /data/media/tv
      PATHRENAMER_ACTION: hardlink
    volumes:
      - ./pathrenamer-config:/config
      - /srv/data:/data

Rename by hand with docker compose exec pathrenamer pathrenamer rename /data/downloads. Everything else, from media servers to Pro, is in the Docker guide.

Requirements

  • Windows 10 or 11, 64-bit
  • An internet connection to look up titles, episode names and subtitles
  • A media server is optional: the names work for Plex, Jellyfin, Emby and Kodi, and PathRenamer can ask any of them to scan
  • Docker version: any 64-bit Intel, AMD or ARM computer with Docker
