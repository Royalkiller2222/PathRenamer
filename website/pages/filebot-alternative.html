A FileBot alternative for Plex on Windows

FileBot is a powerful, long-running media renamer. If you're on Windows, use Plex, and want something you can use in a minute without learning a naming language, PathRenamer may suit you better. Here is an honest comparison.

Where PathRenamer is different

  • Made for Plex out of the box. No format expression to write: movies, TV shows, anime, multi-episode files, daily shows, specials and editions get Plex's names by default.
  • See everything first. Every new name is in the preview before a file moves. Unsure matches are marked, and one right-click fixes a row: new name, episode, or a different match.
  • Subtitles from release folders. Subs\2_English.srt and Spanish (Latin America).srt become Movie (2021).eng.srt and Movie (2021).spa.srt, numbered when there are several in one language.
  • Undo at any time. The rename history can put back any earlier rename, even after a restart.
  • Automation without scripts. Point the watch folder at Downloads, tick a box, and new files are renamed, given subtitles, and scanned into Plex.
  • Free for renaming. Pro is only for the automatic parts.

When FileBot is the better choice

  • You're on macOS or Linux, or want to run on a server without a screen.
  • You want command-line automation or your own scripts.
  • You need very custom naming rules, or databases and media types PathRenamer doesn't cover, such as music.

Switching from FileBot

  1. Install PathRenamer and pick your library folders.
  2. If your FileBot format added extra details, set the same in Settings → Formats; the defaults already follow Plex's naming.
  3. Choose Hard-link in Settings → Options if your torrents should keep seeding.
  4. Turn on the watch folder in Tools → Watch Folder to replace a post-processing script.
